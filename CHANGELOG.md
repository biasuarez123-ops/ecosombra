# Changelog — EcoSombra

## Histórico de alterações

### Desenvolvimento inicial
- Criação da estrutura inicial do projeto.
- Implementação do servidor com Node.js e Express.
- Desenvolvimento do cadastro e login de usuários.
- Implementação do mapa com Leaflet e OpenStreetMap.
- Criação das funções de cadastro, edição e exclusão de locais.

### Banco de dados
- Criação das tabelas usuarios e locais_sombra.
- Utilização do SQLite local e PostgreSQL em produção.
- Proteção de senhas com bcryptjs.
- Implementação de consultas SQL parametrizadas.

### Correções e melhorias
- Atualização dos locais iniciais de demonstração para Porto Velho, Rondônia.
- Atualização da documentação e dos arquivos de configuração.
- Preparação do projeto para implantação pública.

### Revisão das sugestões de IA
- Análise e adaptação das sugestões conforme os requisitos do projeto.
- Verificação das funcionalidades por meio de testes automatizados.
